## Store Listing Metadata

### Short Description
A lightweight, fast, minimalist Markdown document reader and editor for Windows.

### Full Description
AburMD is a production-quality desktop application designed to solve one task exceptionally well: reading and editing Markdown documents locally.

- **Instant Viewing**: Double-click any `.md` file to read clean rendered GFM Markdown instantly.
- **Multi-Tab Interface**: Work with multiple documents concurrently with tab shortcuts (`Ctrl+T`, `Ctrl+W`, `Ctrl+Tab`).
- **Explicit Edit Mode**: Click `[ Edit ]` or press `Ctrl+S` to edit Markdown source cleanly without heavy IDE overhead.
- **Fixed Zinc Design System**: Deep Dark (`#09090B`) and Light (`#FAFAFA`) Zinc neutral palettes paired with 8 selectable accent colors.
- **100% Local & Private**: Completely offline, zero telemetry, zero accounts required.
